WayFilesBest for

Parallel chats

Open a second chat in an editor tab with ⧉ or Ctrl+Alt+Shift+P (Cmd+Alt+Shift+P on macOS). Each chat has its own model, its own terminals, and its own history. If two chats try to change the same file, Phew stops the second one and says why.

Agents in Git worktrees

Run Phew: New Agent in Worktree. Describe the task, choose the model of the agent, and name the branch. The agent works in a separate folder on its own branch, so your files do not change. When it is done, compare, merge, or remove the branch from the chat.

Subagents

An agent can give research tasks to subagents with the delegate tool: for example, one finds every caller of a function while another maps how a feature works. Up to three run at once by default (phew.subagents.maxParallel). Each one only reads: it cannot change files, run commands, or ask you. Its card in the chat shows the model, the current step, and the report.

Ask for it in plain words: “Use subagents to find where network errors are handled and how the tests are set up, then plan the fix.”

Different models for different agents

  • Choose a strong model for the chat that writes the code, and a fast one for subagents with phew.subagents.model.
  • An agent may also name one of your models for a subagent.
  • Two keys of one provider work side by side, each in its own chat.

Know what each agent is doing

The list of chats shows the state of each one: Needs input, Model quiet when a model has sent nothing for a minute, On and the name of a fallback model, Failed, and Done. When a chat that you do not look at fails or waits for you, VS Code shows a notification with the reason.
