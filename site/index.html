And the everyday things

Undo anything

Find, fork, and edit
Search all chats by their messages, fork any message to try another way, or edit it and send again.
Parallel agents

Subagents
The agent sends research tasks to helpers that read in parallel, each with the model it needs, and report back.

Never stuck

Start in a minute

  1. Install Phew

    One click opens VS Code with Phew ready to install. You can also search for Phew in the Extensions view.

    Install in VS Code Visual Studio Marketplace

  2. Connect a model

    Open the Phew view. It shows what is ready on your computer, such as GitHub Copilot or a key in your environment, and free ways to start. Pick one, and Connect and test checks that it works.

  3. Ask, or click Phew it!

    Describe a change in the chat, or put the cursor on an error and press Ctrl+Alt+. (Cmd+Alt+. on macOS).

On VSCodium or another editor that uses Open VSX, install Phew from Open VSX. Every release also has the .vsix file on GitHub.

Your code, your rules

  • You choose where code goes

    Phew sends code only to the model provider that you choose. With a local model, it never leaves your computer.

  • Secrets stay out

    Phew does not read .env files and keys, and removes secrets from command output.

  • Risky commands ask first

    Commands such as git push --force or terraform apply always wait for you.

  • No telemetry

    Phew collects nothing. Your statistics stay on your computer.

Questions

Is Phew free?

Yes. Phew is free and open source under the Apache License 2.0. You pay only your model provider, or nothing with a local model or a GitHub Copilot plan that you already have.

Which editors and systems does it run on?

VS Code {{engine}} or newer, and editors that install extensions from Open VSX, such as VSCodium. It runs on Linux, macOS, and Windows, with bash, zsh, fish, PowerShell, or sh.

Can I use Phew at work?

Yes. Phew signs in through your company with short-lived tokens (Google Vertex AI, Azure with Entra ID, or a gateway), follows the rules of your team from AGENTS.md and the rule files of other agents, and collects no telemetry. Commands that change something ask first, and you can block commands for good.

How many tokens does it use?

As few as the task needs. Phew keeps the start of each request the same, so the prompt cache of the provider works: with Anthropic, later steps read the instructions and the conversation at 10% of the price. Old outputs leave the context, and large files come as an outline first. Each task shows its tokens and cost, and you can set a budget per task.

Does my code leave my computer?

Only to the model provider that you choose: your prompts, the files that the agent reads, and the output of tools. Use Ollama, LM Studio, or vLLM to keep everything local.

What if the agent breaks something?

Each request is a checkpoint, and Restore checkpoint reverts all changes after it. Each change also has Undo in the editor. In the default mode, commands that change something ask you first.

Can another agent continue my work?

Yes. After each task, Phew writes a short handoff note in .phew/handoff/. With your consent, it points AGENTS.md to the latest note, so other agents read it too. Phew also follows your AGENTS.md rules.

How do I report a bug or ask for a feature?

Open an issue on GitHub. For security problems, follow SECURITY.md.
