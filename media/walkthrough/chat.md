# Ask and change code

Open the Phew view and choose a mode (`Shift+Tab` switches it):

| Mode   | What Phew does                                    |
| ------ | ------------------------------------------------- |
| Ask    | Answers questions. Changes nothing.               |
| Plan   | Writes a plan. Changes nothing.                   |
| Code   | Edits files and runs commands with your approval. |
| Debug  | Finds the root cause, then fixes it.              |
| Review | Reviews your changes.                             |

Each chat starts with an overview of your project, so the agent knows the stack and the commands.

Type `@` to attach files, problems, Git changes, terminal output, or an earlier chat.
Paste or drop screenshots; a long pasted text waits as a chip.
`Ctrl+F` finds words in the chat, and **Fork from here** on your message tries another way in a new chat.
Press `↑` in an empty input to reuse an earlier request.
