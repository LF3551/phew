# Ask and change code

Open the Phew view and choose a mode:

| Mode   | What Phew does                                    |
| ------ | ------------------------------------------------- |
| Ask    | Answers questions. Changes nothing.               |
| Plan   | Writes a plan. Changes nothing.                   |
| Code   | Edits files and runs commands with your approval. |
| Debug  | Finds the root cause, then fixes it.              |
| Review | Reviews your changes.                             |

Type `@` to attach files, problems, Git changes, or terminal output.
Paste or drop screenshots into the input.
Press `↑` to reuse an earlier request.
