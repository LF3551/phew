# Review every change

By default, Phew applies a change and shows it in the editor.
Each change has **Keep** and **Undo** buttons, and the editor title has **Keep All** and **Undo All**.
Above the input, the files to review show with their lines added and removed, and **Keep** and **Undo** for each file.

Each request is also a checkpoint.
**Restore checkpoint** in the chat reverts all file changes made after it, and **Edit** on your message takes the chat back to it.

Prefer to approve first? Open the auto-approve panel under the input and set **Edits** to **Ask first**.
