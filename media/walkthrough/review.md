# Review every change

By default, Phew applies a change and shows it in the editor.
Each change has **Keep** and **Undo** buttons, and the editor title has **Keep All** and **Undo All**.

Each request is also a checkpoint.
**Restore checkpoint** in the chat reverts all file changes made after it.

Prefer to approve first? Set **Review mode** to `chat` in the toolbar of the chat.
