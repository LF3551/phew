# Brand

## Name

- Write the name as **Phew**, with a capital P.
- Use the tagline **"Bug fixed. Phew."**
- Do not use the name or logo in a way that suggests an official Pi or Microsoft product.

## Logo

The logo shows two closed, relieved eyes and a sweat drop.
It shows the feeling after a hard bug is fixed.

| File | Use |
| --- | --- |
| `resources/icon.svg` | Source of the full-color logo, 256 x 256 |
| `resources/icon.png` | Extension icon for the VS Code Marketplace and Open VSX, 256 x 256 |
| `resources/icon-128.png` | Small raster logo, 128 x 128 |
| `resources/icon-512.png` | Large raster logo for websites and presentations, 512 x 512 |
| `resources/phew.svg` | Monochrome 24 x 24 icon for the VS Code activity bar and views |
| `resources/social-preview.png` | GitHub social preview, 1280 x 640 |

Rules:

1. Do not change the colors, the proportions, or the position of the drop.
2. Keep empty space around the logo of at least 1/8 of its width.
3. Use `phew.svg` only where VS Code applies the theme color.
4. Generate PNG files from the SVG sources.
   Do not edit PNG files directly.
